<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Meta third-party script → application page | External JS executing in an authenticated dashboard session |
| Meta popup `postMessage` → application state | An untrusted cross-origin message carrying identifiers that become a provisioning request |
| User keyboard input → browser memory | BYO credentials typed into the page |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-08 | Information Disclosure | third-party Meta script present on pages rendering debtor data | mitigate | Loaded with `next/script strategy="lazyOnload"` from inside `EmbeddedSignupButton` only, never from the root layout; grep-asserted |
| T-08-17b | Spoofing | a forged `postMessage` triggering provisioning with someone else's WABA | mitigate | The handler validates the message origin before acting, and the backend registers the sender against the tenant's own freshly created subaccount (plan 08-07), so a WABA the tenant does not control is rejected by Twilio |
| T-08-17c | Information Disclosure | Meta short-lived token or `phoneNumberId` persisted in browser storage or a URL | mitigate | Held in local component state only for the duration of the call; a test asserts no storage write occurs |
| T-08-17d | Denial of Service | an ad-blocker leaving a tenant with no way to connect WhatsApp | mitigate | The `sdk_unavailable` fallback is mandatory and offers the BYO path; asserted by test |
| T-08-17e | Information Disclosure | BYO credentials rendered back into the DOM after save | mitigate | `SecretField` from plan 08-16 shows `lastFour` only and clears local state on save |
| T-08-17f | Denial of Service | indefinite polling burning API quota and battery | mitigate | 15-second interval, visibility-gated, hard stop at 10 minutes with a manual refresh (UI-SPEC A-10) |
| T-08-SC | Tampering | npm/pip/cargo installs | mitigate | slopcheck + blocking human checkpoint for [ASSUMED]/[SUS] — not applicable: no package is installed; the Meta SDK is a runtime script tag, not a dependency |
