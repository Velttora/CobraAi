## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User keyboard input → browser memory | Payment gateway credentials are typed here |
| Tenant-authored template → debtor-facing URL | A string the tenant controls becomes a link sent to third parties |
| API response → rendered panel | Provider error text is rendered verbatim into the page |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-08 | Information Disclosure | payment gateway secret rendered back into the DOM | mitigate | Every secret field is `SecretField` from plan 08-16, which shows `lastFour` only and clears local state on save |
| T-08-18b | Tampering | a non-TLS or attacker-controlled payment template saved | mitigate | `validateExternalLinkTemplate` blocks the submit button client-side, and plan 08-14 enforces the same validator server-side — the browser check is convenience, not the control |
| T-08-18c | Spoofing | preview showing a different URL from the one debtors receive | mitigate | Preview and production share `resolveExternalLinkTemplate` from `@cobrai/utils`; asserted by an equality test |
| T-08-18d | Information Disclosure | provider error text rendered as raw HTML | mitigate | Rendered as React text children, which escapes by default; never `dangerouslySetInnerHTML` |
| T-08-18e | Tampering | a stray provider change silently orphaning issued payment links | mitigate | Provider change is gated by `ConfirmDialog` with copy stating that already-issued links keep working while new ones change gateway |
| T-08-18f | Information Disclosure | webhook URL shown for a provider that has none, implying automatic confirmation exists | mitigate | The block renders only when the integration view carries a non-null `webhookUrl`; `external_link` and `transfer` instead show the manual-reconciliation caveat (D-14) |
| T-08-SC | Tampering | npm/pip/cargo installs | mitigate | slopcheck + blocking human checkpoint for [ASSUMED]/[SUS] — not applicable: no package is installed in this plan |
