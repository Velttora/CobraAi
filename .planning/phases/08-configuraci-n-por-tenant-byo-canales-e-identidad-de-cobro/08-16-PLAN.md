## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User keyboard input → browser memory | A typed credential exists in plaintext in the page for the duration of the session |
| API response → React Query cache | Anything cached here is inspectable through devtools and may persist across navigation |
| Component state → DOM | A value rendered into an attribute or text node is readable by any script on the page |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-08 | Information Disclosure | full secret rendered into the DOM | mitigate | `SecretField` renders no input in the Filled state and shows `lastFour` only; a test asserts `container.innerHTML` never contains a full secret in any state |
| T-08-16b | Information Disclosure | secret persisted into the React Query cache, localStorage or a URL | mitigate | The entered value lives in local component state only, cleared on unmount and after save; the mutation response type is `IntegrationView`, which structurally cannot carry a value |
| T-08-16c | Information Disclosure | password manager or browser autofill capturing the field | mitigate | `autoComplete="off"`, `data-1p-ignore`, `spellCheck={false}` |
| T-08-16d | Tampering | a destructive action fired by a stray click or keystroke | mitigate | `ConfirmDialog` on every destructive action, initial focus on Cancel rather than the destructive button, and overlay-click dismissal disabled for `tone: "danger"` |
| T-08-16e | Denial of Service | a user unable to complete or escape a dialog with the keyboard | mitigate | Focus trap, `Escape` to close and focus restoration, each covered by a test |
| T-08-SC | Tampering | npm/pip/cargo installs | mitigate | slopcheck + blocking human checkpoint for [ASSUMED]/[SUS] — not applicable: no package is installed. shadcn is deliberately not initialized (UI-SPEC A-01) |
